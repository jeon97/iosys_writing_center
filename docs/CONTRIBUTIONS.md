# 담당 업무와 기여 내용

SVN 작업 사본에서 작성자 `joshuajeon`으로 확인되는 변경 파일과 실제 Controller, Service, Mapper, JSP 구조를 기준으로 정리했습니다.

## 로그인과 세션 관리

기관별로 다른 로그인 방식을 공통 로그인 화면에서 처리하도록 개발했습니다.

- 내부 사용자 정보와 계정 사용 상태 조회
- 로그인 실패 횟수 확인 및 성공 후 초기화
- 설정된 기관에 따라 외부 인증 API 호출
- 학생, 교직원, 상담자, 관리자 권한 구분
- 사용자 ID, 이름, 권한, 학년 등 세션 정보 구성
- 동일 계정의 기존 세션 확인과 교체
- 개인정보 동의 여부에 따른 이동 화면 분기
- 마지막 접속 IP와 접속 일시 처리

## SSO 로그인과 로그아웃

- SSO 진입, 사용자 식별, 인증 결과 처리 화면 연동
- SSO 토큰 검증 실패 화면 구성
- 일반 로그아웃과 SSO 로그아웃 경로 분리
- 로그아웃 시 사용자 세션 정리
- 권한에 따른 로그아웃 이후 이동 화면 처리

## 접속 로그 관리

- 기간, 사용자, 접속 정보 조건 검색
- 전체 건수와 목록을 분리 조회해 페이징 적용
- 조회 조건을 유지한 엑셀 자료 생성
- 지정 연도 이전의 접속 로그 삭제
- 목록 조회·삭제·다운로드 권한 확인

## 활동 로그 관리

- 화면과 버튼 단위의 관리자 활동 로그 조회
- 로그인 활동 데이터에서 사용자 ID 추출
- 기간별 활동 로그 엑셀 다운로드
- 보존기간이 지난 활동 로그 삭제
- 관리 작업 자체를 별도 로그로 기록

## 게시판과 콘텐츠 화면

- 일반 게시판 등록·수정·상세 화면
- 도서 게시판 등록·수정 화면
- CKEditor 설정과 입력 화면 연동
- 부가 콘텐츠 등록·수정 화면
- 사용자용과 관리자용 편집 화면 정리

## 사용자·강좌 검색과 결과 화면

- 학사 사용자와 일반 사용자 검색 팝업
- 글쓰기 상담에 연결할 강좌 검색
- 상담 유형 검색 화면
- 기관별 결과 리포트 화면
- 메인, 하위 페이지, 사이트맵 구성

## SVN 작업 사본에서 확인한 범위

| 프로젝트 | 본인이 마지막으로 수정한 파일 | 주요 영역 |
|---|---:|---|
| 글쓰기 지원 시스템 | 89개 | 로그인·SSO, 로그, 게시판, 검색, 리포트 |
| 기본 배포 버전 | 43개 | 공통 로그인, 로그, 콘텐츠 화면 |
| 기관 적용 버전 | 19개 | 게시판, 강좌 검색, 메인 화면 |

파일 수는 커밋 수나 기여 비율이 아니라 현재 SVN 작업 사본에서 확인 가능한 변경 범위입니다.
