# 기관 SSO와 세션 처리

글쓰기 시스템은 일반 로그인과 기관 SSO를 함께 지원했습니다. 인증 성공만 확인하는 것이 아니라 사용자 유형, 관리자 접근 조건, 개인정보 동의 상태와 기존 로그인 세션을 함께 판단해야 했습니다.

## 구현 기준

- SSO 응답의 서명과 유효시간을 검증한 뒤 내부 사용자와 연결
- 외부에서 전달된 이동 주소는 허용된 경로만 사용
- 사용자 유형과 권한으로 학생·교직원·관리자 화면 분기
- 동일 계정의 기존 세션을 만료시키고 새 세션으로 교체
- 로그아웃 시 로컬 세션과 기관 로그아웃 흐름을 함께 처리

[SsoSessionService](../samples/operations-core/src/main/java/com/portfolio/writing/auth/SsoSessionService.java)는 이 판단 순서를 공개용으로 재작성했습니다. 기관 코드, 실제 서명 방식과 내부 주소는 제외했습니다.
